## Payer360 Implementation Plan

### Context

I explored the Provider360 application thoroughly. It uses:
- **Frontend:** React 19 + TypeScript + Vite + Tailwind CSS 4 + React Router + TanStack React Query + Plotly.js
- **Backend:** Flask proxy (port 3001) that forwards SQL to Snowflake REST API using PAT auth
- **Data:** Snowflake medallion architecture (RAW → INT → CUR → APP/ML) with dimension/fact/mart pattern
- **Pattern:** Each dashboard page uses `useSnowflakeQuery(key, sql)` to fetch data from pre-built mart tables, renders KPI cards + Plotly charts

### Architecture (mirroring Provider360)

```
PAYER360_RAW → PAYER360_INT → PAYER360_CUR → PAYER360_APP
                                            → PAYER360_ML
```

### KPI Dashboards & Underlying Tables

#### 1. Medical Loss Ratio (MLR)
- **Route:** `/mlr`
- **KPIs:** MLR %, Incurred Claims ($M), Quality Improvement Spend ($M), Admin Expense Ratio %
- **Mart:** `PAYER360_CUR.FINANCIAL.MART_MEDICAL_LOSS_RATIO`
- **Grain:** 1 row per line of business per month
- **Key columns:** `LINE_OF_BUSINESS`, `PERIOD_DATE`, `PREMIUM_EARNED`, `INCURRED_CLAIMS`, `QUALITY_IMPROVEMENT_EXPENSE`, `ADMIN_EXPENSE`, `MLR_PCT`, `IS_COMPLIANT` (>= 80% for individual/small group, >= 85% for large group)

#### 2. Claims Denial Rate
- **Route:** `/denials`
- **KPIs:** Denial Rate %, Total Denied ($M), Top Denial Reason, Appeal Overturn Rate %
- **Mart:** `PAYER360_CUR.CLAIMS.MART_CLAIMS_DENIALS`
- **Grain:** 1 row per claim line
- **Key columns:** `CLAIM_ID`, `MEMBER_ID`, `PROVIDER_NPI`, `SERVICE_DATE`, `CHARGE_AMT`, `DENIAL_REASON`, `DENIAL_CATEGORY`, `IS_DENIED`, `IS_APPEALED`, `APPEAL_OUTCOME`, `LINE_OF_BUSINESS`, `PLAN_TYPE`

#### 3. Member Renewal Rate / Policy Renewal Rate
- **Route:** `/renewals`
- **KPIs:** Renewal Rate %, Lapsed Policies, Net Member Growth, Avg Tenure (months)
- **Mart:** `PAYER360_CUR.MEMBERSHIP.MART_MEMBER_RENEWALS`
- **Grain:** 1 row per member-policy-period
- **Key columns:** `MEMBER_ID`, `POLICY_ID`, `PLAN_TYPE`, `LINE_OF_BUSINESS`, `EFFECTIVE_DATE`, `TERM_DATE`, `RENEWAL_FLAG`, `LAPSE_FLAG`, `TENURE_MONTHS`, `PREMIUM_MONTHLY`, `RISK_SCORE`

#### 4. Net Promoter Score / Member Satisfaction
- **Route:** `/satisfaction`
- **KPIs:** NPS Score, Promoter %, Detractor %, Avg Satisfaction (1-10), Grievance Rate
- **Mart:** `PAYER360_CUR.MEMBER_EXPERIENCE.MART_MEMBER_SATISFACTION`
- **Grain:** 1 row per survey response
- **Key columns:** `SURVEY_ID`, `MEMBER_ID`, `SURVEY_DATE`, `NPS_SCORE`, `NPS_CATEGORY` (Promoter/Passive/Detractor), `SATISFACTION_SCORE`, `PLAN_TYPE`, `TOPIC`, `IS_GRIEVANCE`, `RESOLUTION_DAYS`

#### 5. Combined Ratio
- **Route:** `/combined-ratio`
- **KPIs:** Combined Ratio %, Loss Ratio %, Expense Ratio %, Underwriting Profit/Loss ($M)
- **Mart:** `PAYER360_CUR.FINANCIAL.MART_COMBINED_RATIO`
- **Grain:** 1 row per line of business per quarter
- **Key columns:** `LINE_OF_BUSINESS`, `QUARTER`, `PREMIUM_EARNED`, `INCURRED_LOSSES`, `LOSS_ADJUSTMENT_EXPENSE`, `UNDERWRITING_EXPENSE`, `LOSS_RATIO_PCT`, `EXPENSE_RATIO_PCT`, `COMBINED_RATIO_PCT`, `UNDERWRITING_RESULT`

#### 6. Claims Settlement Cycle
- **Route:** `/settlement`
- **KPIs:** Avg Days to Settle, Clean Claim Rate %, Auto-Adjudication Rate %, Pending Claims Count
- **Mart:** `PAYER360_CUR.CLAIMS.MART_CLAIMS_SETTLEMENT`
- **Grain:** 1 row per claim
- **Key columns:** `CLAIM_ID`, `MEMBER_ID`, `PROVIDER_NPI`, `RECEIVED_DATE`, `ADJUDICATED_DATE`, `PAID_DATE`, `DAYS_TO_ADJUDICATE`, `DAYS_TO_PAY`, `IS_CLEAN_CLAIM`, `IS_AUTO_ADJUDICATED`, `CLAIM_STATUS`, `LINE_OF_BUSINESS`

#### 7. Provider Network Stability / Turnover Rate
- **Route:** `/network`
- **KPIs:** Network Size, Turnover Rate %, New Providers Added, Avg Contract Term (years), Network Adequacy Score
- **Mart:** `PAYER360_CUR.NETWORK.MART_PROVIDER_NETWORK`
- **Grain:** 1 row per provider-contract-period
- **Key columns:** `PROVIDER_NPI`, `PROVIDER_NAME`, `SPECIALTY`, `CONTRACT_START`, `CONTRACT_END`, `IS_ACTIVE`, `IS_TERMINATED`, `TERMINATION_REASON`, `CONTRACT_YEARS`, `CLAIMS_VOLUME`, `MEMBER_PANEL_SIZE`, `QUALITY_SCORE`, `REGION`
